# bench/ — reproducible benchmark harness

Everything behind the numbers in `../FINDINGS.md`, runnable by anyone.

## Layout

| file | what |
|---|---|
| `build_inputs.py` | round-1 inputs (~9k tokens). Uses Headroom's own transcript generators; the generated `inputs/*.json` are committed so the round reproduces without them. |
| `build_adversarial.py` | round-2 adversarial inputs (30k+ tokens, deterministic seeds — regenerates byte-identical files). |
| `gen_llm_inputs.py` | **bias-removal**: transcripts generated by an *independent* LLM via OpenRouter (not our scripts), with needles we plant and verify. |
| `pruners/jev_prune.py` | Jev (TypeSafe decision model) keep/drop pruner, p ≥ 0.5. Needs `OPENROUTER_API_KEY`. |
| `pruners/headroom_prune.py` | Headroom 0.38.0 baseline. Needs `pip install headroom-ai`. |
| `pruners/jev_dedup.py` | second-pass redundancy framing experiment. |
| `pruners/laya_prune.py` | local Laya 0.3.5 pruner (deprioritized; needs local weights). |
| `score.py` | reduction %, evidence recall, latency, cost → markdown table + `summary.json`. |
| `inputs/` | the 6 benchmark transcripts + evidence lists. |
| `run.sh` | generate → prune → score, end to end. |
| `research/run.py` | deep-research compression: fetched pages → citation-worthy excerpts (deterministic, $0). 40.1% chars on the synthetic 8-page corpus; needles + cited quotes verbatim. |

## Reproduce

```bash
export OPENROUTER_API_KEY=sk-or-v1-...   # transient; never written to disk
./run.sh
```

Expected (Jev column): 12/12 needles recalled across all 6 inputs;
Headroom column: 0/2 on `mixed_grind` (the documented failure mode).

## Bias-removal round

```bash
python3 gen_llm_inputs.py --model google/gemini-2.5-flash --n 3
python3 pruners/jev_prune.py inputs/llm_sre.json outputs/llm_sre_jev.json
python3 score.py outputs/llm_sre_jev.json
```

The generator model is interchangeable — swap `--model` for any OpenRouter
model to check the results aren't an artifact of one generator.
