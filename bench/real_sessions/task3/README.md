# wc — Word Count CLI

A simple word-count tool.

## Usage

Count words in a file and show the top 5 most frequent words:

```
python3 wc.py README.md
```

Expected output:

```
Total words: 42
Top 5 words:
  the: 4
  a: 3
  word: 3
  count: 2
  file: 2
```

Count words in any text file:

```
python3 wc.py myfile.txt
```
